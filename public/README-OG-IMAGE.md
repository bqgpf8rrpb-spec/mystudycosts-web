# Social Media Image (OG Image)

## Required Image

Please add an `og-image.jpg` file to this directory with the following specifications:

- **Filename**: `og-image.jpg` (or `og-image.png`)
- **Dimensions**: 1200x630 pixels (recommended for Open Graph)
- **Format**: JPG or PNG
- **File Size**: Keep under 1MB for fast loading

## Content Suggestions

The image should include:
- MyStudyCosts logo/branding
- Visual representation of the calculator
- Text: "Calculate Your Study Costs in Germany"
- Professional, clean design matching the site's navy-blue theme

## Usage

This image will be automatically used for:
- Facebook/LinkedIn sharing (Open Graph)
- Twitter/X sharing (Twitter Cards)
- Other social media platforms

The image is referenced in `app/[locale]/layout.tsx` in the metadata configuration.
